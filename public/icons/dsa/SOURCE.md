# DSA map marker

The white rose-and-hands artwork is the unmodified monochrome DSA logo from the organization's official logo-download folder, converted from EPS into SVG paths.

- Design guide: https://design.dsausa.org/national-identity/logos/
- Official EPS: https://drive.google.com/file/d/11UzoMDBT8PHDIWKOq1wGDhia2n0d7HDk/view
- Retrieved: 2026-10-15

`logo-white.svg` preserves the converted original. `marker.svg` places it inside an authored geographic pin. The pin uses `--marker-fill` and `--marker-border` CSS variables, with a black default outline. Calendar colors change the pin background; the white logo paths remain unchanged.
